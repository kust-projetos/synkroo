## Focal Point

**Primary screen (conversas/ hub):** MessageComposer is the focal point on the WhatsApp tab — the message input and send button are the dominant interactive element, positioned at the bottom of the message list with high visual prominence.

---

## Key Interaction Patterns

### Contact Profile WhatsApp Tab
1. User clicks "WhatsApp" tab in contact profile
2. WhatsApp tab shows: message history (scrollable), message composer at bottom
3. Each outbound message shows inline status badge (sent/delivered/read)
4. User types message, clicks "Enviar mensagem" CTA
5. Loading state on button during send, then confirmation inline

### Campaign Creation Wizard
1. User clicks "Criar campanha" on campanhas page
2. Dialog opens: step 1 (type selection: reativacao/follow-up/aniversario)
3. Step 2: audience preview based on smart filter
4. Step 3: template selection + customization with placeholder validation
5. Step 4: schedule date/time picker
6. Step 5: confirmation with summary
7. On confirm: campaign created, redirect to campaign detail with metrics

### Reminder Configuration
1. User opens appointment confirmation handler settings
2. Per procedure type: timing dropdown (24h/48h/1 week) + template textarea
3. Placeholders rendered as chips: {{paciente_nome}}, {{data}}, {{horario}}, {{dentista}}
4. Save validates placeholders match regex `^[a-zA-Z0-9_]+$`
