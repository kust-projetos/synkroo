**src/services/contacts/timeline.service.ts:**

Since there is no `patient_observations` table, the timeline for patients uses: appointments, messages (via conversations), and the patients.notes text field. For leads: lead_activities, messages (via conversations), and appointments (via linked patient_id).

Define timeline types:
```typescript
export type TimelineSourceType = 'appointment' | 'message' | 'lead_activity' | 'note';
export type TimelineEventType = 'created' | 'confirmed' | 'cancelled' | 'no_show' | 'sent' | 'received' | 'call' | 'email' | 'meeting' | 'status_change' | 'qualification' | 'note';

export interface TimelineEvent {
  id: string;
  source: TimelineSourceType;
  event_type: string;
  description: string;
  event_timestamp: string;
  contact_id: string;
  contact_type: 'patient' | 'lead';
  metadata: Record<string, unknown>;
}

export interface TimelinePage {
  events: TimelineEvent[];
  next_cursor: string | null;
}
```

Implement `getContactTimeline(clinicId, contactId, contactType, options)`:
- `options: { cursor?: string; limit?: number; typeFilter?: TimelineSourceType }`
- Default limit 20
- Use Supabase RPC or raw SQL query via `.rpc()` for UNION ALL, OR use parallel queries and merge in code

**Approach: Parallel queries + merge in code** (more maintainable than raw SQL RPC):

For a **patient** contact:
1. Query appointments WHERE patient_id = contactId AND clinic_id = clinicId. Map to TimelineEvent with source='appointment'.
2. Query conversations WHERE patient_id = contactId AND clinic_id = clinicId, then query messages for those conversations. Map to TimelineEvent with source='message'.
3. Read patients.notes as a single 'note' event (if not empty).

For a **lead** contact:
1. Query lead_activities WHERE lead_id = contactId. Map to TimelineEvent with source='lead_activity'.
2. Query conversations WHERE lead_id = contactId, then messages for those. Map to 'message'.
3. If lead has patient_id, also query appointments for that patient. Map to 'appointment'.

After gathering all events:
- If typeFilter provided, filter by source type
- Sort all events by event_timestamp DESC
- Apply cursor-based pagination: cursor is base64-encoded `timestamp::source_id`. Items with event_timestamp < cursor timestamp, with source_id as tiebreaker
- Slice to limit, return events + next_cursor (base64 of last item's timestamp::id)

**src/lib/hooks/use-queries.ts:**
Add to existing file:
```typescript
import { useInfiniteQuery, useMutation, useQueryClient } from '@tanstack/react-query'

export function useContactTimeline(id: string, type: string, sourceFilter?: string) {
  return useInfiniteQuery({
    queryKey: [queryKeys.contacts, id, 'timeline', type, sourceFilter],
    queryFn: async ({ pageParam }) => {
      const params = new URLSearchParams({ type, limit: '20' })
      if (pageParam) params.set('cursor', pageParam)
      if (sourceFilter) params.set('source', sourceFilter)
      const res = await fetch(`/api/contacts/${id}/timeline?${params}`)
      if (!res.ok) throw new Error('Failed to fetch timeline')
      return res.json()
    },
    initialPageParam: '',
    getNextPageParam: (lastPage) => lastPage.next_cursor ?? undefined,
    enabled: !!id && !!type,
    staleTime: 30_000,
  })
}

export function useContactConsents(contactId: string, contactType: string) {
  return useQuery({
    queryKey: [queryKeys.consents, contactId, contactType],
    queryFn: async () => {
      const res = await fetch(`/api/consents?contact_id=${contactId}&contact_type=${contactType}`)
      if (!res.ok) throw new Error('Failed to fetch consents')
      return res.json()
    },
    enabled: !!contactId && !!contactType,
  })
}

export function useGrantConsent() {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: async (input) => {
      const res = await fetch('/api/consents', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(input) })
      if (!res.ok) throw new Error('Failed to grant consent')
      return res.json()
    },
    onSuccess: (_data, variables) => {
      queryClient.invalidateQueries({ queryKey: [queryKeys.consents, variables.contact_id, variables.contact_type] })
    },
  })
}

export function useRevokeConsent() {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: async (input) => {
      const res = await fetch('/api/consents', { method: 'PATCH', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(input) })
      if (!res.ok) throw new Error('Failed to revoke consent')
      return res.json()
    },
    onSuccess: (_data, variables) => {
      queryClient.invalidateQueries({ queryKey: [queryKeys.consents, variables.contact_id, variables.contact_type] })
    },
  })
}
```
