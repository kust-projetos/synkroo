### Task 2: Create useKanban hook with conflict resolution

<action>
Create `src/hooks/use-kanban.ts`:
- Export useKanbanBoard function
- Takes options: { onError?: (error: Error) => void }
- Returns { onDragEnd } callback

onDragEnd implementation (MEDIUM-1 - concurrent modification handling):
1. Extract destination.droppableId and draggableId
2. Extract current version/timestamp from lead being dragged
3. Apply optimistic update to kanban-leads query cache
4. Call PATCH /api/leads/${leadId}/stage with { stage_id: newStageId, version: leadVersion }
5. On 409 Conflict (concurrent modification):
   - Invalidate queries to force refetch
   - Call onError with message "Lead was modified by another user. Please refresh."
6. On other errors: invalidate queries and call onError callback

For the API side, the PATCH /api/leads/[id]/stage handler will check:
- If version/timestamp in request body matches current lead version
- If not, return 409 Conflict with current lead state
</action>

### Task 11: Create score thresholds theme constant

<action>
Create `src/lib/theme/score-thresholds.ts`:
```typescript
export const SCORE_THRESHOLDS = {
  cold: { max: 30, color: 'bg-red-500', label: 'Frio' },
  warm: { min: 30, max: 60, color: 'bg-yellow-500', label: 'Morno' },
  hot: { min: 60, color: 'bg-green-500', label: 'Quente' }
} as const;

export function getScoreColor(score: number): string {
  if (score < SCORE_THRESHOLDS.cold.max) return SCORE_THRESHOLDS.cold.color;
  if (score < SCORE_THRESHOLDS.hot.min) return SCORE_THRESHOLDS.warm.color;
  return SCORE_THRESHOLDS.hot.color;
}

export function getScoreLabel(score: number): string {
  if (score < SCORE_THRESHOLDS.cold.max) return SCORE_THRESHOLDS.cold.label;
  if (score < SCORE_THRESHOLDS.hot.min) return SCORE_THRESHOLDS.warm.label;
  return SCORE_THRESHOLDS.hot.label;
}
```
</action>

| T-02-04 | Tampering | DnD stage update | mitigate | Server validates stage belongs to user's clinic before update, version check prevents concurrent overwrite |

| T-02-06 | Tampering | Convert endpoint | mitigate | Requires patient_id in body, validates lead exists and belongs to clinic |
| T-02-07 | Denial | DnD concurrent | mitigate | 409 returned on version conflict, client shows refresh prompt |
