# Phase 2 Plan 03: WhatsApp Lead Capture (PIPE-05)

## Goal

Modify the inbound WhatsApp webhook to automatically create leads when an inbound message arrives from an unknown phone number. Keyword-based scoring determines the initial lead score.

## Background

Phase 2 built the Kanban board with leads management. Phase 3 built the WhatsApp messaging UI. This plan bridges them — when a new WhatsApp message arrives from an unknown number, a lead is automatically created so the clinic can follow up.

## Context

@src/app/api/messages/inbound/route.ts -- existing webhook handler
@src/services/leads/leads.service.ts -- existing leads service
@src/services/pipeline/stages.service.ts -- getDefaultStageId() from plan 02-01

## Decisions (from discuss-phase)

1. **Trigger**: Any inbound message from phone NOT in contacts
2. **Data captured**: phone, timestamp, message text. Name from existing contact if found, else "Desconhecido"
3. **Flow**: inbound webhook → phone known? → NO → create lead (source=whatsapp, default stage) → YES → update last_contact, recalc score
4. **Initial score**: keyword-based

## Keyword Scoring

| Keywords | Points |
|----------|--------|
| "orcamento", "preço", "quanto custa", "valor" | +30 |
| "consulta", "agendar", "marcar", "horário" | +25 |
| "tratamento", "procedimento", "dentista" | +20 |
| Any other message | +5 |

<action>
Add to `src/services/leads/leads.service.ts`:

```typescript
export interface LeadCaptureResult {
  created: boolean;
  leadId: string;
  score: number;
  wasExisting: boolean;
}

export async function captureLeadFromWhatsApp(
  phone: string,
  messageText: string,
  clinicId: string
): Promise<LeadCaptureResult> {
  const defaultStageId = await getDefaultStageId(clinicId);
  const messageKeywords = extractWhatsAppKeywords(messageText);
  const score = calculateWhatsAppLeadScore(messageKeywords);

  // Check if phone already exists as a contact
  const existingContact = await createTypedClient()
    .from('contacts')
    .select('id, name')
    .eq('phone', phone)
    .eq('clinic_id', clinicId)
    .single();

  if (existingContact) {
    // Update last_contact and recalculate score
    await createTypedClient()
      .from('leads')
      .update({ 
        last_contact: new Date().toISOString(),
        score: messageKeywords.length > 0 ? score : undefined
      })
      .eq('phone', phone)
      .eq('clinic_id', clinicId);
    return { created: false, leadId: existingContact.id, score, wasExisting: true };
  }

  // Check if lead already exists for this phone
  const existingLead = await createTypedClient()
    .from('leads')
    .select('id')
    .eq('phone', phone)
    .eq('clinic_id', clinicId)
    .single();

  if (existingLead) {
    await createTypedClient()
      .from('leads')
      .update({ last_contact: new Date().toISOString() })
      .eq('id', existingLead.id);
    return { created: false, leadId: existingLead.id, score, wasExisting: true };
  }

  // Create new lead
  const { data: newLead } = await createTypedClient()
    .from('leads')
    .insert({
      phone,
      name: 'Desconhecido',
      source_type: 'whatsapp',
      stage_id: defaultStageId,
      score,
      clinic_id: clinicId,
      last_contact: new Date().toISOString()
    })
    .select('id')
    .single();

  return { created: true, leadId: newLead.id, score, wasExisting: false };
}

function extractWhatsAppKeywords(text: string): string[] {
  const lower = text.toLowerCase();
  const keywords: string[] = [];
  
  if (/\b(orçamento|preço|quanto custa|valor)\b/.test(lower)) keywords.push('budget');
  if (/\b(consulta|agendar|marcar|horário)\b/.test(lower)) keywords.push('appointment');
  if (/\b(tratamento|procedimento|dentista)\b/.test(lower)) keywords.push('treatment');
  
  return keywords;
}

function calculateWhatsAppLeadScore(keywords: string[]): number {
  if (keywords.includes('budget')) return 30;
  if (keywords.includes('appointment')) return 25;
  if (keywords.includes('treatment')) return 20;
  return 5;
}
```

## Threat Model

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|-------------|
| T-02-05-01 | Spoofing | Lead capture | mitigate | Webhook requires auth — only authenticated WhatsApp messages trigger capture |
| T-02-05-02 | Tampering | Score injection | mitigate | Score calculated server-side from keywords, not from client input |
| T-02-05-03 | Denial | Mass WhatsApp spam | mitigate | Lead created once per phone; repeated messages update existing lead |

## Success Criteria

1. Inbound WhatsApp message from unknown phone creates a lead with source_type='whatsapp'
2. Lead is placed in the default pipeline stage (getDefaultStageId)
3. Score is +30 for budget keywords, +25 for appointment, +20 for treatment, +5 for others
4. If phone exists as contact or lead, last_contact is updated and score recalculated
5. Lead capture failure does not block message storage
6. captureLeadFromWhatsApp is exported from leads.service.ts
