## Layout Patterns

### Pattern 1: Book Appointment Dialog (pre-filled from contact/lead)
- **Source:** Extends `AppointmentDialog.tsx`
- **Entry points:** Contact profile "Novo Agendamento" button (CAL-01), Lead card "Agendar" button (CAL-02)
- **Pre-fill behavior:**
  - From contact: `patientName` and `patientPhone` auto-filled from contact record
  - From lead: same pre-fill + lead conversion trigger available
- **Layout:** Same as AppointmentDialog (DialogContent, form fields, footer CTAs)

### Pattern 2: Contact Appointments Tab
- **Source:** `src/components/contacts/contact-appointments-tab.tsx` (new)
- **Location:** New tab in contact detail panel, between `Financeiro` and end
- **Tabs within:** `Proximos` | `Anteriores`
- **List items:** Compact cards showing date, time, procedure, dentist, status badge
- **CTA:** `Novo Agendamento` button at top right of tab content

### Pattern 3: Waitlist Panel
- **Source:** `src/components/waitlist/waitlist-panel.tsx` (new)
- **Location:** `/dashboard/lista-espera` or modal from contact profile
- **Layout:** List of contacts waiting, sorted by priority/date added
- **Auto-fill behavior:** When appointment cancelled, system suggests waitlist contacts matching procedure/dentist availability
- **Actions per item:** `Agendar` (opens BookAppointmentDialog pre-filled), `Remover` (confirmation)

### Pattern 4: Pipeline Analytics Dashboard
- **Source:** `src/components/reports/pipeline-analytics-dashboard.tsx` (new)
- **Location:** `/dashboard/relatorios/pipeline` or tab in reports section
- **Charts:**
  - Funnel/stage bar chart: leads per stage, conversion rates (REPORT-01)
  - Avg conversion time metric card (REPORT-02)
  - Inactive patients list with last contact date (REPORT-03)
  - Upsell opportunities: patients with completed treatments, no follow-up in X days (REPORT-04)
- **Layout:** Stat cards at top + charts below + tables for lists

### Pattern 5: Financial Reports Dashboard
- **Source:** `src/components/reports/financial-reports-dashboard.tsx` (new)
- **Location:** `/dashboard/relatorios/financeiro` or tab in reports section
- **Period selector:** Month/Quarter/Year selector at top
- **Charts:** Bar charts (Recharts) for revenue, payments, outstanding by period (REPORT-05)
  - Revenue: sum of budget values accepted
  - Payments: sum of payments received
  - Outstanding: revenue minus payments
- **Export:** `Exportar Relatorio` button top right (REPORT-06)

### Pattern 6: Report Export Button
- **Source:** `src/components/reports/report-export-button.tsx` (new)
- **Formats:** CSV (default), PDF (requires jspdf)
- **Behavior:** Select format in dropdown, click export, browser downloads file

### Pattern 7: LGPD Export/Anonymize Dialogs
- **Source:** `src/components/lgpd/lgpd-export-dialog.tsx` + `lgpd-anonymize-dialog.tsx` (new)
- **Export dialog:** Lists all patient data types, generates ZIP or JSON file (LGPD-02)
- **Anonymize dialog:** Confirmation step with impact description, requires typed confirmation, creates audit log entry (LGPD-03)

## Interaction Contracts

### Book Appointment Pre-fill (CAL-01, CAL-02)
| Interaction | Behavior |
|-------------|----------|
| Click `Novo Agendamento` on contact profile | Opens AppointmentDialog with patientName + patientPhone pre-filled |
| Click `Agendar` on lead card | Opens AppointmentDialog with lead pre-filled, also shows `Converter Lead` option |
| On appointment save from lead | System creates patient record from lead, links appointment |

### Contact Appointments Tab (CAL-03, CAL-04)
| Interaction | Behavior |
|-------------|----------|
| Tab loads | Fetch appointments where patient_id matches, show upcoming first |
| Click appointment card | Expand to show full details (dentist, procedure, notes, status) |
| Status badges | `confirmado` (green), `cancelado` (red), `realizado` (blue), `remarcado` (amber) |

### Waitlist Auto-fill (CAL-05)
| Interaction | Behavior |
|-------------|----------|
| Appointment cancelled | System scans waitlist for matching procedure + dentist |
| Auto-suggest notification | Toast or badge: "X contatos na lista de espera podem preencher este slot" |
| Accept auto-fill | Opens BookAppointmentDialog pre-filled with waitlist contact |
| Manual scheduling | Dentist can ignore suggestion and leave slot empty |

### Pipeline Analytics (REPORT-01, REPORT-02, REPORT-03, REPORT-04)
| Interaction | Behavior |
|-------------|----------|
| Stage conversion chart | Bars show count of leads at each stage; click bar to filter lead list |
| Avg conversion time | Calculated from lead creation to first confirmed appointment |
| Inactive patients | Filtered list: no appointments in last 90 days, with last contact date |
| Upsell opportunities | List: treatment completed >30 days ago, no active budget |

### Financial Reports (REPORT-05, REPORT-06)
| Interaction | Behavior |
|-------------|----------|
| Period change | Charts re-render with selected period data |
| Hover on bar | Tooltip shows exact value |
| Export button | Dropdown to choose CSV or PDF, then download |

### LGPD Export (LGPD-02)
| Interaction | Behavior |
|-------------|----------|
| Click `Exportar Dados` | Dialog lists all data categories (personal, financial, appointments) |
| Confirm export | System generates JSON/ZIP file, browser downloads |
| Progress indicator | Show progress bar if export takes >2 seconds |

### LGPD Anonymize (LGPD-03)
| Interaction | Behavior |
|-------------|----------|
| Click `Anonimizar Dados` | Dialog shows impact summary (what will be anonymized) |
| Type confirmation | User must type "CONFIRMAR" to enable proceed button |
| Execute anonymize | POST to API, API replaces PII with anonymous hashes, creates audit log |
| Result toast | "Dados anonimizados com sucesso. ID do audit: XXXXX" |
