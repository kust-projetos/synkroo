Create new file: src/app/api/lgpd/anonymize/route.ts

POST handler for LGPD-03 (anonymization with audit):

1. Authenticate via validateApiAuth()
2. Accept body: { patientId: string }
3. Generate a unique request ID: crypto.randomUUID()
4. Transaction (in order):
   a. UPDATE patients SET:
      - name = 'ANONYMIZED_' + random 8-char hex
      - phone = NULL
      - email = NULL
      - cpf = NULL
      - birth_date = NULL
      WHERE id = patientId
   
   b. UPDATE appointments SET notes = '[ANONYMIZED]' WHERE patient_id = patientId
   
   c. UPDATE budgets SET notes = '[ANONYMIZED]' WHERE patient_id = patientId
   
   d. UPDATE leads SET name = '[ANONYMIZED]', phone = NULL, email = NULL WHERE patient_id = patientId (if any)
   
   e. INSERT INTO audit_logs (clinic_id, action, record_id, metadata, created_at):
      - action = 'patient_anonymized'
      - record_id = patientId
      - metadata = JSON { requestId, originalPatientId, anonymizedAt: timestamp }
      - clinic_id from auth

5. Return { success: true, auditId: requestId }

Use createTypedClient() with supabase.rpc() for transaction if supported, otherwise sequential updates with error checking.

Anonymized value pattern: 'ANONYMIZED_' + first 8 chars of crypto.randomUUID()
