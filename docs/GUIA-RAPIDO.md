## Status de Agendamento

| Status | Ação | Cor |
|--------|------|-----|
| Agendado | Aguardando confirmação | Azul |
| Confirmado | Paciente confirmou | Verde |
| Em andamento | Consulta acontecendo | Azul escuro |
| Concluído | Finalizado | Cinza |
| Cancelado | Cancelado | Vermelho |
| No-show | Não compareceu | Laranja |

## Ações Rápidas

### Agendamento
```
1. Agendamentos > + Novo
2. Selecionar paciente (ou criar novo)
3. Escolher dentista
4. Selecionar data/hora
5. Adicionar procedimento
6. Salvar
```

### Cancelar Agendamento
```
1. Abrir agendamento
2. Clicar em "Cancelar"
3. Confirmar
4. (Opcional) Adicionar à lista de espera
```

### Adicionar à Lista de Espera
```
1. Lista de Espera > + Nova Entrada
2. Selecionar paciente
3. Data preferida
4. Horário preferido
5. Prioridade (1-10)
6. Salvar
```

## Resolução de Problemas

| Problema | Solução |
|----------|---------|
| WhatsApp desconectado | Configurações > WhatsApp > Reconectar |
| IA não entende | Falar com atendente: "quero falar com alguém" |
| Horário ocupado | Oferecer lista de espera |
| Paciente não encontrado | Cadastrar novo paciente |
