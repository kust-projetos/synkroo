## Registry rules

- R1/R2 blockers are resolved locally or environmentally before escalation.
- R3 runs only with configured authorization; capture a sanitized external receipt.
- R4/R5 stop only the owning dependency branch. Never pause independent READY nodes.
- After two identical failures, stop repeating, record root cause and try one orthogonal approach.
- A blocker is not a status promotion. The ledger is authoritative for item status.
