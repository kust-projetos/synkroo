## Resumo
- **Requisito F5.04:** Waitlist: CRUD e preenchimento de vaga idempotente.
- **Implementação:**
  - Repositório Operacional (`src/modules/operacional/repositories/waitlist-repository.ts`):
    - `findWaitlistById(id, clinicId)`: busca por ID escopada por clínica.
    - `listWaitlist(clinicId, opts)`: listagem com filtros (status, paciente, dentista, data) ordenada por prioridade decrescente e data de criação.
    - `insertWaitlist`: criação de entrada na fila.
    - `updateWaitlist`: atualização de prioridade, horários, procedimentos, dentistas e notas.
    - `cancelWaitlistEntry`: cancelamento com registro de motivo.
    - `preencherVagaWaitlist`: transação com `SELECT ... FOR UPDATE` no PostgreSQL para travar a linha da waitlist, checar idempotência (se já agendado, retorna o mesmo `appointmentId` sem criar duplicatas), criar agendamento na tabela `appointments`, associar `scheduledAppointmentId` e atualizar status para `scheduled`.
  - Ações do Módulo Operacional (`src/modules/operacional/actions/`):
    - `entrarWaitlist` (`operacional.entrarWaitlist`)
    - `listarWaitlist` (`operacional.listarWaitlist`)
    - `obterWaitlist` (`operacional.obterWaitlist`)
    - `atualizarWaitlist` (`operacional.atualizarWaitlist`)
    - `cancelarWaitlist` (`operacional.cancelarWaitlist`)
    - `preencherWaitlist` (`operacional.preencherWaitlist`): executa preenchimento idempotente e mapeia constraint `23P01` para `ActionError('conflict')`.
  - Serviço e Repositório Legacy (`src/services/waitlist/waitlist.service.ts` e `src/repositories/waitlist/index.ts`):
    - `fillWaitlistSlot`, `getWaitlistEntryById`, `updateWaitlistEntry` adicionados e integrados.
  - Rotas de API (`src/app/api/waitlist/route.ts` e `src/app/api/waitlist/fill/route.ts`):
    - `GET /api/waitlist` (listagem e busca por ID via query param)
    - `POST /api/waitlist` (adicionar paciente à lista com rate-limit)
    - `PATCH /api/waitlist` e `PUT /api/waitlist` (atualizar entrada)
    - `DELETE /api/waitlist` (cancelar entrada)
    - `POST /api/waitlist/fill` (preencher vaga idempotente com rate-limit)
