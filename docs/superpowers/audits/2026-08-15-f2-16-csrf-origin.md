# F2.16 — Origin/CSRF em rotas cookie-authenticated

- Middleware não trata mais todos os `/api/auth/*` como Auth.js internals.
- Rotas customizadas (`login`, `logout`, `refresh`, `signup`, `switch-clinic`) passam pelo guard Origin/CSRF.
- Somente endpoints Auth.js explícitos/callback continuam fora do guard para permitir o protocolo do provider.

|---|---|
| Matriz middleware + custom auth CSRF | PASS — 10 testes |
| `npx tsc --noEmit --pretty false` | PASS |

| `git diff --check` | PASS |
