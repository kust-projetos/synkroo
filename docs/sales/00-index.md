- **Conteúdo:** Processo completo, scripts, GPCT, objeções, fechamentos

- **Páginas:** ~12
- **Conteúdo:** Metodologia, fórmulas, exemplos
- **Uso:** Entender como calcular, validar números

### 03 - Template de Proposta
- **Páginas:** ~12
- **Conteúdo:** Estrutura completa com placeholders
- **Uso:** Base para criar propostas

- **Uso:** Apresentação detalhada

## Quick Start para Novo Vendedor

### Semana 1 - Estudo
1. Ler **01-sales-manual.md** completo
2. Ler **11-competitor-benchmark.md**
3. Estudar **12-technical-faq.md**

### Semana 2 - Prática
1. Usar **05-sales-cheat-sheet.md** em ligações
2. Praticar cálculo com **06-roi-spreadsheet.md**
3. Montar proposta com **03-proposal-template.md** + **07-proposal-example.md**

### Semana 3+ - Campo
1. Usar **08-feature-card-short.md** para envios rápidos
2. Usar **09-case-studies.md** como social proof
3. Anexar **10-terms-and-conditions.md** às propostas
