# E2E Testing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create comprehensive E2E test suite covering all pages, features, and API endpoints using Playwright with Feature Modules + Helpers architecture.

**Architecture:** Tests organized by feature domain (auth, calendar, patients, etc.) with shared helper functions for navigation, form interaction, and API calls. Auth uses Playwright `storageState` to login once and reuse session across all authenticated tests.

**Tech Stack:** Playwright, TypeScript, Next.js 15 App Router, Supabase Auth

export type CalendarView = 'day' | 'week' | 'month' | 'professionals'

  week: 'Semana',
  month: 'Mês',
